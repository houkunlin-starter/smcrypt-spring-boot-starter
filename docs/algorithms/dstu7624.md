# DSTU7624（Kalyna）

[返回 README](../../README.md) | [算法索引](README.md)

## 简介

DSTU7624（又称 Kalyna）是乌克兰国家标准对称分组密码，支持 128 / 256 / 512 位密钥。

## 密文格式与算法前缀

前缀为 `DSTU7624ENC(...)`，编码规则见 [密文格式](../cipher-format.md)：

```
DSTU7624ENC(base64,xxxxxxxx)
```

## 默认参数

| 项目     | 值                          |
|----------|-----------------------------|
| 变换串   | `DSTU7624/ECB/PKCS5Padding` |
| 密钥长度 | 16 / 32 / 64 字节           |
| 分组长度 | 16 字节                     |
| IV       | 16 字节（CBC 等模式）       |

## 配置项

```properties
smcrypt.dstu7624.key=<密钥的 hex / Base64>
smcrypt.dstu7624.mode=CBC
smcrypt.dstu7624.iv=<16 字节 IV>
```

## 示例

```properties
smcrypt.dstu7624.key=<密钥的 hex / Base64>
smcrypt.dstu7624.mode=CBC
smcrypt.dstu7624.iv=<16 字节 IV>
```

## 安全说明

- 乌克兰地区标准（Kalyna），安全；
- CBC 必须使用随机且不可复用的 IV；可配置 `smcrypt.dstu7624.mac` 启用 encrypt-then-MAC。
