# GOST3412-2015（Kuznyechik）

[返回 README](../../README.md) | [算法索引](README.md)

## 简介

GOST3412-2015（又称 Kuznyechik）是俄罗斯国家标准对称分组密码。本 starter 的密文前缀为
`GOST3412ENC(...)`，对应的 JCE 算法名为 `GOST3412-2015`。

## 密文格式与算法前缀

前缀为 `GOST3412ENC(...)`，编码规则见 [密文格式](../cipher-format.md)：

```
GOST3412ENC(base64,xxxxxxxx)
```

## 默认参数

| 项目     | 值                               |
|----------|----------------------------------|
| 变换串   | `GOST3412-2015/ECB/PKCS5Padding` |
| 密钥长度 | 32 字节（256 位）                |
| 分组长度 | 16 字节                          |
| IV       | 16 字节（CBC 等模式）            |

## 配置项

```properties
smcrypt.gost3412.key=<32 字节密钥的 hex / Base64>
smcrypt.gost3412.mode=CBC
smcrypt.gost3412.iv=<16 字节 IV>
```

## 示例

```properties
smcrypt.gost3412.key=<32 字节密钥的 hex / Base64>
# 如需 CBC，需配置 16 字节 IV
smcrypt.gost3412.mode=CBC
smcrypt.gost3412.iv=<16 字节 IV>
```

## 安全说明

- 俄罗斯地区标准（Kuznyechik），256 位密钥，安全；
- CBC 必须使用随机且不可复用的 IV；可配置 `smcrypt.gost3412.mac` 启用 encrypt-then-MAC。
